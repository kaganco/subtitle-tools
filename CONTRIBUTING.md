# Contributing to Subtitle Tools

Thank you for your interest in contributing to **Subtitle Tools**! We welcome all contributions, including bug reports, feature suggestions, documentation improvements, and pull requests.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs & Suggesting Features
* Check existing [Issues](https://github.com/your-username/subtitle-tools/issues) to make sure your issue hasn't been reported already.
* Open a new Issue using the appropriate template:
  * 🐛 **Bug Report**: Provide clear steps to reproduce, expected vs. actual behavior, and browser info.
  * 💡 **Feature Request**: Explain the feature, why it would be helpful, and any proposed design ideas.

### 2. Submitting Pull Requests (PRs)
1. **Fork** the repository.
2. Create a new topic branch for your changes:
   ```bash
   git checkout -b feature/my-cool-feature
   ```
3. Keep code clean and self-contained:
   * Maintain the 100% client-side architecture (no backend or external API calls required).
   * Ensure mobile responsiveness and cross-browser compatibility.
4. Test your changes locally in multiple browsers (Chrome, Firefox, Safari/Edge).
5. **Commit** your changes with clear, descriptive commit messages:
   ```bash
   git commit -m "feat: add character encoding auto-detection for Baltic encodings"
   ```
6. **Push** to your fork and submit a **Pull Request** against the `main` branch.

---

## 🎨 Code Style Guidelines
* Standard HTML5, CSS3, and ES6+ JavaScript.
* Use clean indentations (2 spaces for HTML/JS/CSS).
* Ensure dark mode aesthetics and responsive CSS layouts are maintained.
* Keep client-side security and privacy as top priority (no remote file uploads).
